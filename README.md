# Botan Cryptography Tutorial

A hands-on C++ tutorial covering cryptography fundamentals using the [Botan](https://github.com/randombit/botan) library. Each lesson is a single self-contained `.cpp` file that you compile and run to see the output.

The lessons follow a natural progression: start with hashing (no keys), move through symmetric and asymmetric encryption, then build up to a full PKI and TLS 1.3 handshake.

## Requirements

- macOS (Apple Silicon or Intel with T2)
- Xcode Command Line Tools (`xcode-select --install`)
- C++20 compiler — bundled with Xcode CLT (`c++ --version` to verify)
- Python 3 — used by Botan's `configure.py` build script

## Project Structure

```
BotanTutorial/
├── 01_hashing.cpp       Source files — one per lesson
├── ...
├── Makefile             Build rules (setup, compile, debug, clean)
├── botan-src/           Botan source tree (git submodule)
├── include/             Generated by make setup — Botan headers
├── lib/                 Generated by make setup — libbotan-3.dylib
└── bin/                 Generated by make setup — internal Botan tools
```

`include/`, `lib/`, and `bin/` are **not tracked by git** — they are produced by `make setup` and stay local.

## Setup

**1. Clone the repository with submodules:**
```bash
git clone --recurse-submodules https://github.com/ahmedmoabdeldayem/BotanTutorial
cd BotanTutorial
```

If you already cloned without `--recurse-submodules`:
```bash
git submodule update --init
```

**2. Build and install Botan from source:**
```bash
make setup
```

This will:
- Configure Botan with debug symbols
- Compile the library (~3–5 minutes)
- Install headers into `include/`
- Install the dynamic library into `lib/`

> **Note:** `make setup` only needs to run once. After that you can compile any lesson directly.

## Compiling and Running a Lesson

```bash
make 01_hashing
./01_hashing
```

Expected output format:
```
MD5:
  <32 hex chars>

SHA-256:
  <64 hex chars>

SHA-3(256):
  <64 hex chars>
...
```

## Compiling All Lessons

```bash

     04_rsa_encrypt 04b_ecdh 05_signatures \
     06_certificates 06b_cert_chain 07_tls
```

---

## Compiling with Debug Symbols

To step through Botan internals in a debugger:

```bash
make debug-01_hashing
./01_hashing
```

Open the folder in VS Code and press `F5` to launch the debugger. The `debug-` prefix builds with `-g -O0` so you can step into Botan's source.

---

## Clean

Remove compiled lesson binaries:
```bash
make clean
```

To fully reset (including the built Botan library), delete `include/`, `lib/`, and `bin/`, then re-run `make setup`.
